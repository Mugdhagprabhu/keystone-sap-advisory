# Keystone SAP Advisory

The website and brand for Ganesh Prabhu's independent SAP consulting practice.

## What's in here

| File | What it is |
|------|------------|
| `index.html` | The main website. Double-click to open it in any browser. |
| `cv.html` | The CV / resume page, with a "Download PDF" button. |
| `brand-guide.html` | The brand reference: logo, colours, fonts, and voice. |
| `assets/logo.svg` | The Keystone logo mark. |
| `assets/favicon.svg` | The small icon shown in the browser tab. |
| `assets/images/` | Photos used on the site. |

Every page is a single self-contained file. There is no build step and nothing to
install. To view any page, just double-click it and it opens in your web browser.

## How to make small changes

The text lives directly inside the HTML files. To change a word, open the file in
any plain-text editor (TextEdit on Mac, Notepad on Windows, or a code editor like
VS Code), find the text, edit it, and save. Refresh the page in your browser to see
the change.

A few things worth knowing before you edit:

- The contact email is currently a placeholder: `ganesh@keystonesapadvisory.com`.
  Search for it and replace it with the real address once it exists.
- Keep the `assets` folder next to the HTML files. If you move a page out on its
  own, the photos and logo will stop showing.

## Hosting it as a live website

These files can be published for free on services like Netlify, Cloudflare Pages,
or GitHub Pages. Ask if you'd like a walk-through.
