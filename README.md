# Mugdha Prabhu — UI/UX & Product Design Portfolio

A playful, design-led React portfolio for Mugdha Prabhu, an emerging UI/UX and product designer with an engineering background.

## Routes

- `/` — home and selected work
- `/work/piqsal` — Piqsal case study
- `/work/vanguard` — Vanguard case study
- `/fun-projects` — UX Hacks side quests and VVS flip card
- `/about` — technology-to-design story
- `/contact` — contact links and Medium placeholder

## Development

```bash
pnpm install
pnpm dev
```

The app lives in `client/`. Project imagery is intentionally represented by replaceable, aspect-ratio-aware placeholders until Mugdha provides the real screenshots and Figma URLs.
